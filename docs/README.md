# AyurKB documentation

Start with the project [README](../README.md) for an overview, quick start and results. Then pick what you need:

| If you want to … | Read |
|---|---|
| understand what the dataset is, why it exists, how it was made and its limits | [DATASHEET.md](DATASHEET.md) |
| look up a table or column | [DATA_DICTIONARY.md](DATA_DICTIONARY.md) (generated by `scripts/09_docs.py`) |
| understand how the pieces fit: data model, conventions, pipeline stages, what to re-run after a change | [ARCHITECTURE.md](ARCHITECTURE.md) |
| learn the Ayurveda, Sanskrit and technical vocabulary | [GLOSSARY.md](GLOSSARY.md) |
| fix or extend the data, add a test, prepare a commit | [../CONTRIBUTING.md](../CONTRIBUTING.md) |
| find known problems and open work to pick up | [KNOWN_ISSUES.md](KNOWN_ISSUES.md) |
| check where each source comes from and its licence | [SOURCES.md](SOURCES.md) |
| build an expert system or decision-support tool on the data | [EXPERT_SYSTEM_GUIDE.md](EXPERT_SYSTEM_GUIDE.md) |
| request permissions from data owners | [permission_requests/](permission_requests/README.md) |

The HTML files in this folder (`*_template.html`) are page templates filled by `scripts/12_report.py` and
`scripts/22_build_tools.py`; edit them, not the generated pages in `release/`.
